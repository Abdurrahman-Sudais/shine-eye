# ShineEye

> Shine your eye. Paste a suspicious message, link, screenshot, or voice note and find out if it's a scam, why, and what to do next, in English, Pidgin, Yoruba, Hausa, or Igbo.

Built for **ForgeHacks 2026** (AI + Cybersecurity track) by **Abdurrahman Sudais** ([@Abdurrahman-Sudais](https://github.com/Abdurrahman-Sudais)).

🚧 Work in progress. The full README (architecture, evaluation results, demo video) lands before submission.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in keys
npm run dev                   # http://localhost:3000
npm test                     # unit tests
```
